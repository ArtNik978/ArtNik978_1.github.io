# Форма 100

Персональный офлайн-трекер тренировок, питания и прогресса. В каждое упражнение встроены две фотографии: исходное и конечное положение.

## Запуск

Откройте `index.html` в браузере. Для установки как PWA или публикации онлайн загрузите всю папку на GitHub Pages, Netlify, Cloudflare Pages или другой статический HTTPS-хостинг.

Локальный запуск через HTTP:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080/fitness-dashboard/`.

## Хранение данных

Данные сохраняются в localStorage браузера. Используйте экспорт JSON в разделе «Настройки» для резервного копирования.
