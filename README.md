# Форма 100 v3

## Новые возможности

- Полная история тренировок с раскрытием каждого упражнения и подхода.
- Во время новой тренировки показываются вес и повторы по каждому упражнению из прошлой тренировки.
- Кнопка «Заполнить» переносит предыдущие значения в текущую тренировку.
- Редактор программы A/B/C: добавление, изменение, удаление и перемещение упражнений.
- Загрузка двух собственных фотографий к каждому упражнению.
- Экспорт полной резервной копии JSON, включая пользовательские фото.
- Экспорт истории подходов в CSV.

## Запуск

Распакуйте архив и загрузите всю папку на Netlify Drop, GitHub Pages либо другой статический HTTPS-хостинг. Для локального запуска:

```bash
python -m http.server 8080
```

## Важно

Данные сохраняются в localStorage браузера. Пользовательские фото автоматически уменьшаются до 1000 пикселей и сжимаются. Регулярно используйте экспорт JSON. При очистке данных браузера локальная история будет удалена.
